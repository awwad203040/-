## 🌟 نظرة عامة / Project Overview
**نور القرآن** هو وحدة مصحف رقمية شريفة كاملة (604 صفحات من مصحف المدينة المنورة) تتيح للمسلم تلاوة القرآن الكريم، البحث في آياته، الاستماع لكبار القراء، مطالعة التفاسير المعتمدة، وتتبع الورد القرآني والختمات، بواجهة عربية أصيلة تدعم اتجاه الكتابة من اليمين لليسار (RTL) وتصميم هادئ ومريح للعين يعتمد ألوان الهوية الإسلامية الفاخرة:
- الأخضر الأساسي: `#123B2A`
- الأخضر الثانوي: `#0B5B43`
- الكريمي / العاجي: `#FBF8EF`
- الذهبي الإسلامي: `#C8A85B`
- خطوط عربية مصحفية رصينة: خط الأميري (`Amiri`)، خط النسخ، وخط تجوال (`Tajawal`).

---

## ⚠️ القواعد الصارمة للنص القرآني / Quran Content Sacred Rules
- **النص القرآني محمي ومقدس**: لا يتم توليد أو صياغة أو كتابة أي آية قرآنية بواسطة الذكاء الاصطناعي على الإطلاق.
- **مصدر موثوق ومعتمد**: جميع الآيات، أرقامها، علامات أجزائها، أحزابها، وتفاسيرها تُجلب حصراً عبر خادم آمن من واجهات **مؤسسة القرآن (Quran Foundation Content API)** الرسمية.
- **الأمان والسرية التامة**: مفتاح العميل السري `QF_CLIENT_SECRET` محمي بالكامل داخل الخادم (`server-only`) ولا يُسرّب أو يُكشف للواجهة الأمامية أو المتصفح.

## 🚀 الميزات والخصائص / Core Features

### 1. تجربة المصحف الكامل (604 صفحات)
- تصفح كامل لجميع صفحات المصحف الشريف الـ 604 بدون استثناء.
- تنقل فوري بين الصفحات بالأسهم، أو بالسحب باللمس على الجوال (Swipe: يمين للسابق، يسار للتالي مراعاة للاتجاه العربي).
- نافذة "انتقل إلى صفحة" من 1 إلى 604 مع التحقق الدقيق من المدخلات.
- وضعان للقراءة:
  - **وضع المصحف (Mushaf Mode)**: نص مصحفي متصل لكل صفحة مع فواصل الآيات الذهبية.
  - **وضع آية آية (Verse Mode)**: قراءة متأنية مع إمكانية التفاعل المنفرد مع كل آية.

### 2. التفاعل المتقدم مع الآيات (Ayah Actions)
عند الضغط على أي آية تظهر قائمة تفاعلية نظيفة (Bottom Sheet):
- **تشغيل التلاوة**: الاستماع للآية أو السورة بصوت القارئ المختار.
- **التفسير المعتمد**: مطالعة تفسير الآية من مصادر موثوقة (التفسير الميسر، الطبري، ابن كثير، القرطبي).
- **حفظ علامة (Bookmark)**: حفظ موضع الآية للرجوع إليه لاحقاً.
- **تدوين الملاحظات (Personal Notes)**: كتابة خواطر وتدبرات شخصية خاصة بالآية مع حفظها محلياً.
- **النسخ والمشاركة**: نسخ الآية بالرسم العثماني وعزوها، أو مشاركتها عبر نافذة المشاركة الأصلية للجوال.

### 3. الصوتيات واختيار القراء (Audio Player & Reciters)
- مشغل صوتي عائم أسفل الشاشة يدعم:
  - التشغيل والإيقاف المؤقت.
  - شريط التقدم للتقديم والتأخير.
  - التحكم في سرعة القراءة (0.5x إلى 2x).
  - ميزة التكرار للتحفيظ والمدارسة.
  - اختيار القارئ المفضل من كوكبة من كبار قراء العالم الإسلامي:
    - الشيخ مشاري راشد العفاسي
    - الشيخ عبد الباسط عبد الصمد (مرتل / مجود)
    - الشيخ عبد الرحمن السديس
    - الشيخ محمود خليل الحصري
    - الشيخ ماهر المعيقلي
    - الشيخ محمد صديق المنشاوي
    - الشيخ أبو بكر الشاطري
    - الشيخ هاني الرفاعي
    - الشيخ سعود الشريم
    - الشيخ سعد الغامدي

### 4. البحث القرآني الذكي (Quran Search)
- بحث نصي فوري في كلمات وآيات القرآن الكريم.
- دعم الانتقال المباشر برقم السورة والآية (مثل: `2:255` لآية الكرسي).
- عرض نتائج البحث مع اسم السورة، رقم الآية، والنص المظلل، مع إمكانية الضغط على النتيجة للانتقال الفوري إلى صفحتها في المصحف.

### 5. تتبع القراءة والختمة (Reading Progress & Khatmah)
- حفظ تلقائي لآخر صفحة وسورة وآية تمت قراءتها.
- زر "متابعة القراءة" في الصفحة الرئيسية يعيد القارئ فوراً لموضعه السابق.
- مؤشر بياني دقيق يوضح نسبة ما تم قراءته من المصحف (مثال: `40.6%` - 245 من 604 صفحة).
- حفظ البيانات محلياً للزوار (`localStorage`) مع جاهزية المزامنة مع قاعدة بيانات PostgreSQL للمستخدمين المسجلين.

### 6. التخصيص والمظهر (Customization)
- التحكم بحجم الخط القرآني وتكبيره وتصغيره بسلاسة.
- الوضع الليلي المريح للعين في القراءة المظلمة (`Night Mode`).
- تصميم متجاوب 100% للجوال والأجهزة اللوحية والحواسيب المكتبية.
- جاهز كـ Progressive Web App (PWA) للعمل كتطبيق جوال مستقل.

## 🛠 الهيكلية والتقنيات المستخدمة / Architecture & Tech Stack
- **الإطار البرمجي**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19).
- **لغة البرمجة**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode).
- **التنسيق والتصميم**: [Tailwind CSS v4](https://tailwindcss.com/) مع متغيرات CSS خاصة ومظهر إسلامي.
- **إدارة التخزين**:
  - في وضع الضيف (Guest): `localStorage` للعلامات والتقدم والإعدادات.
  - في وضع الحساب المسجل: PostgreSQL عبر `database/schema.sql`.
- **واجهة البيانات**: Quran Foundation Content API عبر مسار آمن في الخادم.

## 🔐 الربط مع مؤسسة القرآن / Quran Foundation API Integration
يستخدم التطبيق بروتوكول **OAuth2 Client Credentials** مع واجهة Quran Foundation:
- **نقطة التحقق**: `https://oauth2.quran.foundation/oauth2/token`
- **نطاق الصلاحيات**: `scope=content`
- **واجهة المحتوى**: `https://apis.quran.foundation/api/v4`
- يقوم الخادم في `src/lib/quran-foundation.ts` بتوليد التوكن وتخزينه تلقائياً مع تجديده قبل انتهائه، وإعادة المحاولة التلقائية عند الخطأ 401.

## ⚙️ إعداد المتغيرات البيئية / Environment Variables
قم بإنشاء ملف `.env.local` بناءً على `.env.example`:

```env
# Quran Foundation API Credentials
QF_ENV=production
QF_CLIENT_ID=your_client_id_here
QF_CLIENT_SECRET=your_client_secret_here

# PostgreSQL Database (Optional for guest mode, required for cloud sync)
DATABASE_URL=postgresql://user:password@localhost:5432/noor_alquran

# Auth & AI (Optional)
AUTH_SECRET=your_nextauth_or_app_secret
OPENAI_API_KEY=
```

## 🗄 قاعدة البيانات / Database Schema
تتوفر هيكلية الجداول في `database/schema.sql` وتدعم:
- `app_user`: حسابات المستخدمين.
- `bookmark`: العلامات المرجعية على مستوى السورة والآية والصفحة مع الملاحظة.
- `reading_progress`: تقدم القراءة وموضع آخر صفحة.
- `user_settings`: تفضيلات الخط والوضع الليلي والقارئ والتفسير.
- `khatmah`: متابعة الختمات القرآنية وتواريخ البدء والانتهاء.
- `daily_wird`: تتبع الورد اليومي وصفحات الإنجاز.
- `recitation_session`: جلسات الاستماع والتلاوة.

## ⌨️ إمكانية الوصول والتنقل بلوحة المفاتيح / Accessibility & Shortcuts
حرصاً على معايير إمكانية الوصول (Accessibility Section 32):
- **السهم الأيسر (Arrow Left)**: الانتقال للصفحة التالية في المصحف.
- **السهم الأيمن (Arrow Right)**: الانتقال للصفحة السابقة في المصحف.
- **مسافة (Space)**: تشغيل / إيقاف الصوت عند نشاط المشغل الصوتي.
- **زر الهروب (Escape)**: إغلاق أي نافذة منبثقة نشطة فوراً.
- جميع الأزرار مزودة بـ `aria-label` باللغة العربية الواضحة لمساعدات الشاشة و`role` ملائم.
